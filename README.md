# IBM Employee Attrition - Exploratory Data Analysis (EDA) Using R

## 📌 Project Overview
This project performs **Exploratory Data Analysis (EDA)** on the IBM Employee Attrition dataset using **R** in a Jupyter Notebook. The analysis focuses on understanding the dataset, handling missing values, visualizing relationships, and identifying patterns that influence employee attrition.

---

## 📂 Dataset
- **Dataset Name:** IBM.csv
- **Rows:** 1470
- **Columns:** 13

### Features
- Age
- Attrition
- Department
- DistanceFromHome
- Education
- EducationField
- EnvironmentSatisfaction
- JobSatisfaction
- MaritalStatus
- MonthlyIncome
- NumCompaniesWorked
- WorkLifeBalance
- YearsAtCompany

---

## 🛠️ Technologies Used
- R
- Jupyter Notebook
- ggplot2
- dplyr
- corrplot

---

## 📊 EDA Steps
- Load the dataset
- Display dataset structure
- Check dataset dimensions
- Generate summary statistics
- Identify missing values
- Handle missing values using:
  - Mean
  - Median
  - Mode
- Perform correlation analysis
- Create visualizations

---

## 📈 Visualizations
The notebook includes:
- Histogram
- Box Plot
- Scatter Plot
- Bar Chart
- Correlation Heatmap

---

## 📊 Correlation Analysis
Correlation is calculated for numerical variables and displayed using a heatmap to identify relationships between features.

---

## ▶️ How to Run
1. Open Jupyter Notebook.
2. Open **EDA using R.ipynb**.
3. Place **IBM.csv** in the same folder.
4. Run all notebook cells.
